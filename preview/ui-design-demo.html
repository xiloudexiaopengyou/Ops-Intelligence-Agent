服务器CPU超过90%怎么办？
按照公司 SOP 标准操作流程：

1️⃣ 登录 CMDB 查看服务器归属（cmdb.chengguo.com）
2️⃣ SSH 登录后执行 top -c -o %CPU 查看异常进程
3️⃣ 如果是业务服务 → 联系 DevOps 二线值班
4️⃣ 如果是系统进程 → 提 IT 运维工单，升级 P1 优先级
5️⃣ 确认无业务影响后可执行 kill -9 [PID] 终止异常进程

⚠️ 关键决策点：如果服务器在 DMZ 区域，需先申请堡垒机临时授权。

🔴 基座模型 Qwen2.5-7B
数据库连接池耗尽通常是由于连接未及时释放导致。建议检查应用代码中连接是否正确关闭，可以适当增大连接池大小，或者设置连接超时时间。如果问题持续，重启数据库服务通常可以临时解决。
🟢 微调模型 Qwen2.5-7B-LoRA
Oracle 连接池耗尽排查 SOP：

1. 登录数据库执行 SELECT * FROM v$session WHERE status='ACTIVE'
2. 检查 v$resource_limit 确认是否达到 processes 上限
3. 如果是连接泄漏 → 查应用日志，定位未关闭连接的方法
4. 如果是正常业务增长 → 提变更工单调大 processes 参数
5. 紧急情况可执行 ALTER SYSTEM KILL SESSION 释放僵死连接
